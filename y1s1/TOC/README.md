# Theory of Computation (TOC)

## Course Overview

Covers the mathematical foundations of computation: formal languages, automata,
computability, and complexity. Also includes an introduction to Knowledge
Representation and Reasoning (KRR).

## Topics

### Theory of Computation
- Formal languages: regular, context-free, context-sensitive, recursively enumerable
- Regular expressions and finite automata (DFA, NFA, ε-NFA)
- Context-free grammars (CFG), pushdown automata (PDA)
- Pumping lemmas for regular and context-free languages
- Turing machines: deterministic, nondeterministic, multi-tape
- Decidability and undecidability; halting problem
- Complexity classes: P, NP, NP-complete, NP-hard
- CYK parsing algorithm

### Knowledge Representation & Reasoning (KRR)
- Propositional and first-order logic
- Description logics (DL): ALC, SHIQ, OWL
- Reasoning: classification, satisfiability, subsumption
- Argumentation theory: abstract argumentation, defeasible reasoning
- Actual causation and causal models
